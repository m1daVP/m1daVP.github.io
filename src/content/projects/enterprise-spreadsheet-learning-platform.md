## Overview

A spreadsheet-based enterprise learning platform built around Excel-like interactive tables, drag-and-drop builders, and data visualizations.

## Approach

- Built complex interactive interfaces including Excel-like tables, drag-and-drop builders, and data visualizations.
- Improved load time by ~50%, overall performance by ~20%, and Google PageSpeed score to 90+.
- Built dashboards and internal workflows supporting different user roles and business processes.
- Grew into a project leadership role and mentored frontend trainees through an internal training program.

## Stack notes

Handsontable powered the Excel-like grid experience, Chart.js handled the data visualizations, on a Vue.js/Node.js/Express.js/MongoDB stack deployed on AWS.
