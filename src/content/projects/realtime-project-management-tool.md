## Overview

A Jira-like real-time task management interface, built with React, Redux-Saga, and TailwindCSS on the frontend and a WebSocket-driven NestJS backend for live task tracking and collaboration.

## Approach

- Built the task management UI in React with Redux-Saga for state and side-effect management.
- Styled the interface with TailwindCSS.
- Implemented real-time task updates and collaboration features over WebSockets.
- Built the backend API and WebSocket layer in NestJS.
