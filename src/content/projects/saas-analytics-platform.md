## Overview

A data-intensive analytics platform for financial forecasting, paired with embeddable widgets that let third-party websites surface the same product flows.

## Approach

- Built a data-intensive analytics platform and embeddable widgets for third-party websites.
- Owned frontend architecture for interactive product flows and complex UI states.
- Optimized rendering performance for real-time, data-heavy interfaces.
- Supported dynamic content delivery and deployment workflows with Strapi, Docker, and CI/CD.

## Stack notes

Strapi runs as the headless CMS behind dynamic content delivery, with WebSockets powering real-time updates on data-heavy views. Docker and GitHub Actions handle the deployment workflow.
