## Overview

An interactive financial forecasting platform that transformed model outputs into a guided scenario-analysis experience. The product was delivered as both a standalone interface and an embeddable widget for integration into external websites.

## Approach

* Built the core frontend architecture and guided workflow for configuring assumptions, exploring forecasts, and reviewing synthesized results.
* Developed interactive scenario-modeling tools that enabled users to adjust key assumptions and evaluate potential outcomes.
* Implemented drag-and-drop interactions, temporary editing states, save and discard behavior, and responsive support for desktop and touch devices.
* Created presentation-oriented result views that translated complex model output into charts, comparative views, heatmaps, and structured slides.
* Integrated the frontend with real-time backend processes and independently designed and owned all typed contracts governing frontend–backend communication.
* Contributed to persistent session storage so users could retain analysis state across connections and service restarts.
* Added automated coverage for critical financial-data transformations and improved reliability around parallel requests, long-running operations, cleanup, and reconnection behavior.
* Supported containerization, health monitoring, deployment preparation, and integration with host-page event systems.

## Outcome

The project evolved from separate models and interface prototypes into a cohesive interactive product. Users could configure scenarios, compare potential outcomes, review results in a presentation-ready format, and return to previously saved analysis states.

## Stack notes

The interface was built with Vue, TypeScript, Pinia, Vite, and Chart.js. Real-time communication was handled through WebSockets, with Python and FastAPI supporting forecasting workflows and PostgreSQL providing persistent session storage. Docker and GitHub Actions supported testing and deployment processes.
