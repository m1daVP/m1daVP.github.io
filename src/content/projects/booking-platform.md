## Overview

A booking platform serving customer-facing booking flows across multiple frontend applications, backed by geolocation-aware business logic.

## Approach

- Developed customer-facing booking flows across multiple frontend applications.
- Contributed to backend functionality supporting booking workflows and business logic.
- Integrated Google Maps APIs and geolocation-based product behavior.
- Supported deployment and environment maintenance using Docker and Linux-based servers.

## Stack notes

Frontend built in Nuxt with TailwindCSS, backend in Laravel/MySQL. Google Maps API integration drives location-aware booking behavior across the customer-facing apps.
